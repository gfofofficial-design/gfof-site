# Alliance project decision brief

November 27, 2026 · Public project worksheet

Project leads can prepare a short discussion brief before making a joint decision. The optional panel sits beside the project introduction. It starts collapsed with a blank draft.

- Ask for a decision and two to four distinct options. Accept an optional decision owner, review date, up to three evidence links, and open questions. Use the shared Alliance parser for HTTPS links. People supply and review their own evidence.
- Generate plain text in the order readers need it. Lead with the decision and options, then show the owner, date, evidence, and open questions. Label missing context explicitly. The heading describes the output as a discussion draft.
- Keep the draft in the tab. The visitor can copy it or download a text file after reviewing it. Use the existing Alliance clipboard timeout and fallback. The project intake reads only its current introduction fields.
- After an edit, hide the former result, revoke its download URL, and ignore stale clipboard feedback. Clear resets the fields and returns focus to the decision. Invalid inputs identify the field to correct. Successful preparation moves focus to the ready draft.

Acceptance covers required fields, duplicate or excess options, invalid dates and links, optional context, keyboard focus, narrow layouts, explicit copy and download, clipboard refusal, and stale export removal. Verify that preparing either draft preserves the other and that decision fields are outside the project-request form.
