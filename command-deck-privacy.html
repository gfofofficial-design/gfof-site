COMMAND DECK // DATA AND PRIVACY

Your data, your controls.

What the public-address viewer sends, what stays on this device, and how to clear it.

Applies to the read-only Command Deck preview. Updated October 9, 2026. Account registration and future financial services require their own disclosures.

When you read a wallet

You enter a public Solana address. The site sends it to its hosting service and the configured Solana RPC provider (Helius when enabled, otherwise Solana's public RPC) to retrieve native SOL and token-account quantities. Token mint addresses are sent to Jupiter for available reference prices. This does not prove that you own the address.

The wallet viewer does not request a seed phrase, private key, signature or token transfer. Never enter those secrets. Reference values may cover only some assets.

Opening a token's Dossier Lens link sends that token mint in the destination URL for a separate structure lookup. The viewer's Explorer link opens the viewed public address on Solana Explorer.

Balances stay in this page visit

The viewer keeps returned balances, reference values, filters and up to twelve SOL observations in page memory. It does not save wallet data to browser storage or a Federation account.

Clear, editing the address or a failed lookup clears the displayed wallet data and visit history. Reloading starts a new page visit. Clear does not remove public blockchain records or logs already held by service providers.

Mission progress is a separate choice

The dashboard reads an existing Explorer Passport from this browser. It does not turn saving on. First Contact keeps completion markers for the current tab session; choosing Remember my progress there saves valid mission completions on this device for later visits.

To remove the remembered passport, open First Contact's Explorer Passport, select Forget remembered progress, then confirm Remove passport. This turns remembered passport saving off. Current-tab badges and your avatar remain, as the confirmation explains.

Closing the tab ends its session storage under normal browser behavior, although browser session restoration can preserve it. Browser settings can clear this site's stored data more broadly; that can also remove other local Federation preferences or progress. Passport badges do not sync to an account or establish verified public leaderboard scores.

Hosting and data providers

Hosting and external data services receive ordinary request metadata and may retain operational logs. The public-address lookup is processed through hosting even though the dashboard does not keep a persistent application wallet record.

This page does not specify or promise those providers' log retention periods. Clearing this page or removing a passport does not erase their records. Provider retention and deletion handling remain separate operational review items.

Public token locks and planning examples

The lock panel reads the site's fixed public GFOF contracts, separately from your entered wallet. It does not represent your staking position. The staking calculator uses an example amount; it does not submit that amount to a staking provider or establish wallet eligibility. Proposed terms and fictional leaderboard entries remain labelled.

Scope of these controls

This describes the dashboard's current data paths and local controls. It does not describe every legacy website form, an account-deletion service, future wallet linking, staking deposits or lending. Those features need their own applicable procedures before release.
