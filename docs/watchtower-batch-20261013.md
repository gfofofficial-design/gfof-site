# Watchtower normalized event boundary — offline only

This processor validates a strict Federation normalized envelope for up to 100 events, a fifteen-minute supplied receipt-time window, exact 32-byte base58 account addresses and 64-byte signatures. It accepts an operator-supplied watchlist of at most twenty distinct accounts with explicit event types, copies that configuration and filters outside-scope events before replay. Unknown keys and malformed events are refused, including outside-scope data. Conflicting watched duplicates refuse the whole batch.

The existing replay core reports duplicates, holds confirmed observations pending, and promotes a repeated observation when its supplied commitment becomes finalized. Only supplied-finalized observations receive reviewed wording. Transfers are not described as sales or profit. Control/lock changes require independent state and contract review before interpreting their effects.

This is not a Helius webhook parser or authentication mechanism. No provider connection, raw webhook endpoint, credential, signature verification, independent finality lookup, cursor, persistent deduplication or notification is activated. Source authenticity remains not_verified, coverage remains not_established, watchlist approval is not verified and deduplication is limited to one batch. Base58 byte validation does not prove an account exists or a transaction occurred. Supplied receipt times can be fabricated; the time check is a format boundary, not authenticated freshness.

Before live monitoring: choose the exact current-mint/account/contract scope; review current provider documentation, available plan and quotas; authenticate ingress before parsing; verify relevant events and finality independently with bounded allowance; persist unique keys and cursor state; handle retries, missed deliveries, rollback/disagreement and retention; test recovery; approve cadence, costs and any notification destination. Do not build a public financial verdict or claim monitoring completeness from this offline boundary.
