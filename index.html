$GFOF Staking

Spec before code.

Staking is on the roadmap for post-bond activation. The Federation will publish a versioned staking specification — open for public comment — before any contract is written. Same pattern as the liquidation spec: design first, comment period, then code.

⚠ NO APY · NO MULTIPLIERS · NO RATES COMMITTED — The staking specification has not been written. No tier structure, lock period, reward formula, or NFT-boost value has been decided. Anyone presenting specific numbers as "what GFOF staking will pay" is not speaking for the Federation.
// 01 · MECHANISM
Non-custodial lock contract
Smart contract holds tokens on-chain with defined release windows. No custodian. Audited before deployment per commitment #003.
// 02 · GOVERNANCE WEIGHT
Locked supply earns voice
Staked $GFOF will carry weight in Federation governance proposals. Weighting formula will be defined in the spec, not retrofitted.
// 03 · NFT INTERACTION
Founding Member integration
If Founding Member NFTs interact with staking, the relationship will be defined in the spec. Any boost value comes from the spec, not from marketing.
// WHY NO NUMBERS YET
Staking parameters depend on variables the Federation does not yet have certainty about: post-bond treasury size, circulating supply dynamics, holder concentration, governance participation rates, and the economics of the lending product the spec exists to support. Publishing speculative APYs before those variables are known would be marketing, not design.
The spec will be published when the inputs justify it. Until then, no tier numbers, no calculator, no rate. The corrections log records every commitment publicly — see galacticfederation.co/corrections.
// SPEC TIMELINE
Spec drafting begins post-bond. Public-comment window will be announced when the draft is ready. Launch timing is not committed and will not be committed until the spec is final. Join Telegram for draft-spec notifications when they happen.
